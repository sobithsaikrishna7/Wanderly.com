# 🌍 Wanderly — Discover Beyond the Ordinary

**Wanderly** is a modern, responsive tourism website designed to help travelers explore beautiful destinations, discover curated travel experiences, and plan their next adventure.

Built using HTML, CSS, and JavaScript, Wanderly features an elegant interface with cinematic travel photography, a premium forest-green and gold color palette, and interactive destination cards.

## ✨ Features

- **Modern Landing Page** — A visually appealing homepage with a cinematic hero section.
- **Destination Explorer** — Discover destinations such as Bali, Santorini, Kyoto, the Swiss Alps, and Manali.
- **Search & Filters** — Search destinations and filter trips by beaches, mountains, and culture.
- **Travel Packages** — View estimated prices, trip durations, and destination ratings.
- **Favorites** — Save and remove favorite destinations during the current session.
- **Login Page** — A matching sign-in interface with email and password fields.
- **Password Visibility** — Toggle password visibility on the login page.
- **Booking Inquiry UI** — An interactive form for entering travel preferences.
- **Responsive Design** — Layouts optimized for desktop, tablet, and mobile devices.
- **Premium Visual Theme** — Forest green, warm ivory, muted gold, and elegant typography.

## 🎨 Design Philosophy

Wanderly uses a clean, travel-inspired visual identity:

- **Forest Green (`#183D35`)** — Trust, nature, and exploration.
- **Warm Ivory (`#FAF8F2`)** — Spaciousness and readability.
- **Muted Gold (`#C69B58`)** — Premium accents and calls to action.
- **DM Sans** — Clean, modern interface typography.
- **Playfair Display** — Elegant headings that complement the travel photography.

The goal is to create a welcoming, premium experience that makes discovering destinations enjoyable.

## ⚠️ Current Limitations

Wanderly is currently a frontend demonstration.

- Authentication is not connected to a backend.
- Google sign-in requires an authentication provider.
- Password recovery is not implemented.
- Booking inquiries are not sent to a server.
- Destination prices and ratings are illustrative rather than verified live offers.
- External images and fonts require an internet connection.

**Security note:** Do not use the frontend demonstration for real user authentication or store passwords in browser-side code.
